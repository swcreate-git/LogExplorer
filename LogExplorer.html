    Combining Filters (A/B/C/D)

    Active filter slots are combined with OR — a line is shown if it matches any enabled filter. Use in-expression operators (AND, OR, NOT) inside a single box for boolean logic.

    Note: Whitespace is NOT a separator. Mark Str is a single token including the space.

    Keywords (AND OR NOT FIRST AFTER LAST BEFORE) are operators only as standalone words — error and CANNOT are plain text.

    An invalid expression (e.g. foo OR, {a) is ignored and its box turns red (the tooltip shows why). Highlights are shown for every valid filter; the checkbox only decides whether that filter takes part in showing/hiding lines.
